# 📝 Environment Variables Checklist for Render

Before deploying to Render, gather all these values. This will make deployment much faster!

---

## ✅ Variables to Prepare

### 1. Supabase Credentials

Get these from: [https://app.supabase.com](https://app.supabase.com) → Your Project → Settings → API

```bash
SUPABASE_URL=https://xxxxxxxxxxxxx.supabase.co
SUPABASE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.xxxxx...
```

**How to get:**
- Go to Supabase Dashboard
- Select your project
- Settings → API
- Copy "Project URL" → `SUPABASE_URL`
- Copy "anon public" key → `SUPABASE_KEY`

---

### 2. Mailtrap SMTP Credentials

Get these from: [https://mailtrap.io](https://mailtrap.io) → Email Testing → SMTP Settings

```bash
MAILTRAP_SMTP_USER=xxxxxxxxxxxxx
MAILTRAP_SMTP_PASS=xxxxxxxxxxxxx
```

**How to get:**
1. Login to Mailtrap
2. Go to "Email Testing" → "Inboxes"
3. Select your inbox (or create one)
4. Click "SMTP Settings"
5. Choose "Python" → "Integration"
6. Copy username and password

---

### 3. Google OAuth Credentials

Get these from: [https://console.cloud.google.com](https://console.cloud.google.com)

```bash
GOOGLE_CLIENT_ID=xxxxxxxxxxxxx.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-xxxxxxxxxxxxx
```

**How to get:**
1. Go to Google Cloud Console
2. Select your project (or create new)
3. APIs & Services → Credentials
4. Click "Create Credentials" → "OAuth 2.0 Client ID"
5. Application type: "Web application"
6. Name: "FYPilot Backend"
7. Authorized redirect URIs: (add after deployment)
   ```
   https://your-render-url.onrender.com/auth/oauth/google/callback
   ```
8. Copy Client ID and Client Secret

**⚠️ Note:** You'll need to update the redirect URI after deployment!

---

### 4. GitHub OAuth Credentials (Optional)

Get these from: [https://github.com/settings/developers](https://github.com/settings/developers)

```bash
GITHUB_CLIENT_ID=xxxxxxxxxxxxx
GITHUB_CLIENT_SECRET=xxxxxxxxxxxxx
```

**How to get:**
1. Go to GitHub Settings
2. Developer settings → OAuth Apps
3. Click "New OAuth App"
4. Fill in:
   - Application name: "FYPilot"
   - Homepage URL: `https://your-frontend.vercel.app`
   - Authorization callback URL: `https://your-render-url.onrender.com/auth/oauth/github/callback`
5. Copy Client ID and Client Secret

---

### 5. Frontend URL

```bash
FRONTEND_APP_URL=https://your-frontend.vercel.app
```

**Where to get:**
- If deployed: Copy your Vercel URL
- If not deployed yet: Use placeholder, update later

---

## 🤖 Auto-Generated by Render

These are automatically generated - no need to prepare:

- ✅ `DATABASE_URL` - Auto-linked from PostgreSQL service
- ✅ `JWT_SECRET` - Auto-generated random string
- ✅ `SESSION_SECRET` - Auto-generated random string
- ✅ `OAUTH_REDIRECT_ORIGIN` - Set to your Render URL after deployment
